The NCIC table defines no code for an unclassifiable or unprinted finger — those exist only in AFIS. This bench leaves the position blank and flags it rather than inventing a value.

IAFIS / AFIS pattern level

AUArch, unspecified — plain and tented alike
WUWhorl, unspecified — all four whorl types
RSRight slant loop
LSLeft slant loop
SRComplete scar
XXAmputation
UCUnable to classify
UPUnable to print — image not supplied

Slant follows the hand: an ulnar loop slants right on the right hand and left on the left hand, and a radial loop does the reverse. The bench derives it from the box number, so you never enter it.

Whorl ridge tracing

Trace the ridge from the extreme left delta toward the right delta. If it passes inside (above) the right delta with three or more ridges intervening, the tracing is inner — I. If it passes outside (below) with three or more intervening, it is outer — O. Every other tracing is meeting — M.
